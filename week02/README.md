# 2주차 - 실습 환경 구축과 버전 관리 기초

## 배운 내용

### 리눅스 실습 환경
- WSL2와 Ubuntu를 이용해 Windows에서 리눅스 명령어를 사용할 수 있다.
- `pwd`로 현재 위치를 확인하고, `cd`로 디렉터리를 이동한다.
- `mkdir`, `touch`, `ls`, `cat` 등으로 디렉터리와 파일을 만들고 확인한다.
- `>`는 파일 내용을 새로 쓰고, `>>`는 기존 내용 뒤에 추가한다.

### Git과 GitHub
- Git은 파일의 변경 이력을 기록하는 도구이다.
- `git status`로 변경 상태를 확인하고, `git add`로 다음 커밋에 포함할 파일을 선택한다.
- `git commit`은 선택한 변경사항을 하나의 버전으로 기록한다.
- 브랜치를 사용하면 `main`과 분리된 공간에서 작업할 수 있다.
- GitHub에 변경사항을 반영하려면 커밋한 뒤 `git push`를 실행해야 한다.

## 새로 배운 명령어

| 명령어 | 하는 일 |
| --- | --- |
| `pwd` | 현재 디렉터리 확인 |
| `ls` | 파일과 디렉터리 목록 확인 |
| `cd` | 디렉터리 이동 |
| `mkdir` | 디렉터리 만들기 |
| `touch` | 빈 파일 만들기 |
| `cat` | 파일 내용 확인 |
| `git status` | Git 작업 상태 확인 |
| `git add` | 커밋할 변경사항 선택 |
| `git commit` | 변경사항을 버전으로 기록 |
| `git log --oneline` | 커밋 기록을 간단히 확인 |
| `git branch` | 브랜치 목록과 현재 브랜치 확인 |
| `git push` | 로컬 커밋을 GitHub에 올리기 |
