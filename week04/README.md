# 4주차 - 자동화와 협업, 네트워크

## 배운 내용

### 셸 스크립트와 자동화
- 절대 경로는 `/`부터 시작하며, 상대 경로는 현재 위치를 기준으로 한다.
- `find`로 파일을 찾고 `grep`으로 파일 안의 내용을 검색할 수 있다.
- 파이프(`|`)는 앞 명령어의 출력을 뒤 명령어의 입력으로 전달한다.
- 셸 스크립트에서는 변수, 인자, 조건문, 반복문을 사용해 반복 작업을 자동화할 수 있다.
- `tar`로 파일을 압축해 백업하고, `diff`로 원본과 복원한 파일의 차이를 확인할 수 있다.

### Git과 GitHub 협업
- 브랜치를 만들면 `main`과 분리된 공간에서 작업할 수 있다.
- 작업 내용을 커밋하고 푸시한 뒤 Pull Request를 만들어 변경사항의 병합을 요청한다.
- 같은 부분을 서로 다르게 수정하면 충돌이 발생할 수 있으며, 내용을 확인하고 해결한 뒤 Merge한다.

### 네트워크
- IP 주소는 통신할 컴퓨터를 찾는 데 사용하고, 포트 번호는 그 컴퓨터의 서비스를 구분한다.
- DNS는 도메인 이름에 해당하는 IP 주소를 찾는 데 사용한다.
- `curl`로 HTTP 요청과 응답을 확인할 수 있다.
- `ss`로 서버가 특정 포트에서 연결을 기다리는지 확인할 수 있다.
- 같은 포트를 두 서버가 동시에 사용하려고 하면 포트 충돌이 발생한다.

## 새로 배운 명령어

| 명령어 | 하는 일 |
| --- | --- |
| `find . -type f -name "*.sh"` | 현재 폴더 아래에서 셸 스크립트 파일 찾기 |
| `grep "ERROR" server.log` | 로그에서 `ERROR`가 포함된 줄 찾기 |
| `head -2 diary.txt` | 파일의 앞 2줄 보기 |
| `tail -1 diary.txt` | 파일의 마지막 1줄 보기 |
| `wc -l diary.txt` | 파일의 줄 수 확인 |
| `ps aux` | 실행 중인 프로세스 확인 |
| `tar -czf backup.tar.gz 폴더명` | 폴더를 압축해 백업 파일 만들기 |
| `diff -rq 원본폴더 복원폴더` | 두 폴더의 차이 확인 |
| `git switch -c 브랜치명` | 새 브랜치를 만들고 이동 |
| `git diff` | 변경된 내용 확인 |
| `ping -c 4 주소` | 상대 장치의 응답 확인 |
| `dig 도메인 +short` | 도메인의 IP 주소 조회 |
| `curl -I URL` | HTTP 응답 헤더와 상태 코드 확인 |
| `ss -tlnp` | 연결을 기다리는 TCP 포트 확인 |
